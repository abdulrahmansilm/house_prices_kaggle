# 🏠 House Prices - Kaggle Competition
 
Predicting house sale prices using Machine Learning (Random Forest Regression).  
This project was built for learning purposes as part of a university AI course.
 
## 📊 Results
| Model | R² Score | Kaggle RMSLE |
|---|---|---|
| Decision Tree | 0.716 | - |
| Random Forest | 0.857 | 0.14691 |

 
 
## 📥 Data
The dataset is provided by Kaggle and cannot be shared publicly due to their terms of service.
 
Download it here:  
👉 https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data
 
 
## 🔧 What the notebook does
1. Load & explore the data
2. Handle missing values (median, mode, "None")
3. One-Hot Encoding for categorical features
4. Train a Random Forest Regressor
5. Evaluate with Cross Validation
6. Generate submission file
## 🛠️ Libraries Used
- pandas
- scikit-learn
- numpy
